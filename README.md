# 🧸 인형 눈알 붙이기

앱인토스(App in Toss) **비게임(엔터테인먼트)** 미니앱 『인형 눈알 붙이기』 프로토타입입니다.
눈이 없는 곰돌이·토끼 인형에 눈알을 **톡! 톡!** 붙이며 잠깐 쉬어가는 미니앱이에요.

- **목탁 두드리기** 스타일의 미니멀 UI: 크림색 배경 위에 카드 테두리 없이 큰 인형 하나,
  상단 한 줄 진행(`눈알 붙이는 중.. 100 남음`)과 얇은 진행 바, 하단 아이콘 탭 바 5개
- **톡·톡 → 쓱!** 리듬: 눈알은 0.15초 만에 톡 붙고, 두 눈을 다 붙이면 0.4초 뒤 바로 다음 인형
- **랜덤 눈 순서(단순 안내)**: 인형마다 **왼쪽·오른쪽 중 먼저 붙일 눈이 랜덤**으로 정해지고, 점선 가이드와 한 줄 안내(`오른쪽 눈부터 톡`)가 그 눈을 가리켜요. 안내는 **순서를 알려 주는 가이드**일 뿐, 판정이 아니에요
- **판정·벌점 없음**: 어느 쪽을 누르든 지금 차례 눈이 정위치에 깔끔하게 붙어요. 흔들림·실수 효과음·경고 문구·콤보 초기화가 없어요
- **특별 주문 인형**: 5~9개마다 랜덤으로 황금 · 리본 · 왕관 인형이 나와요(가상 기록 2배)
- **더보기** 메뉴: 친구에게 공유 · 알림 받기 · 설정 및 기록 · 안내 및 출처
- **비게임(엔터테인먼트) 기준**: 승패 · 점수 · **콤보** · 등급 · 제한시간 · 순위 없음
- 순수 클라이언트 사이드 정적 웹앱 (`iframe`, `eval`, SSR, 외부 라이브러리 없음)
- 외부 폰트·이미지·CDN 요청 0건 (그림은 인라인 SVG, 사운드는 Web Audio 합성음)

## 1. 실행 방법

정적 파일이라 별도 빌드 없이 바로 열 수 있어요.

```bash
# 방법 1: 그냥 열기
open index.html            # macOS / 브라우저에 파일을 끌어다 놓기

# 방법 2: 로컬 서버 (권장 — 사운드/저장/공유 동작이 실제와 가장 비슷)
python3 -m http.server 8765
# → http://localhost:8765
```

앱인토스 QR 테스트는 실제 기기(토스 앱)에서 진행해 주세요. PC 크롬과 iOS 사파리/토스 웹뷰는
사운드·저장·공유·알림 동작이 다를 수 있습니다.

### 파일 구성

| 파일 | 내용 |

## 2. 화면과 흐름

휴대폰 세로 화면(390×844 기준)에서 스크롤 없이 한 화면이 되도록 여백을 잡았습니다.

1. **상단 바** — 뒤로가기 · 곰돌이 아이콘 · `인형 눈알 붙이기`
2. **박스 진행 한 줄** — 왼쪽 `1박스 포장 중..`, 오른쪽 `100 남음`(숫자 강조) + 8px 진행 바
   - 인형 하나를 끝낼 때마다 바가 차오르고, 끝점 불빛·숫자·`+1`이 톡 튀어 오릅니다.
   - 100개를 채우면 `1박스 완료!`로 바뀌며 바가 초록빛이 되고, 잠시 뒤 **`2박스 포장 중..`으로 바로 이어져요.**
   - 바 아래 한 줄: `이번 박스 37/100개` · `누적 1박스`
3. **인형** — 화면 폭을 거의 채우는 주인공. 얼굴을 톡톡 누르면 눈이 붙어요.
4. **한 줄 안내** — 지금 할 일(`오른쪽 눈부터 톡`) 또는 완성 멘트
5. **오늘 요약** — 왼쪽 `오늘 N개`, 오른쪽 `가상 기록 N원`(박스를 채우면 `N박스 포장 완료 · 가상 기록 N원`)
6. **고지 한 줄** — `인형 눈알 붙이는 부업 · 기록은 전부 가상이에요`
7. **아이콘 탭 바(5개)** — 인형 · 테마 · 소리 · 부스터 · 더보기
   - 열려 있는 시트의 탭에만 은은한 둥근 배경이 붙습니다.

### 리듬 (끊김 없이 반복)

- 눈이 없는 인형이 뜨면 안내된 쪽부터 톡톡: **먼저 붙일 눈은 인형마다 랜덤**(왼쪽/오른쪽)이고, 두 번째는 반대쪽이에요.
  - 안내는 **순서 가이드일 뿐**이에요. 반대쪽이든 다른 곳이든, 누르면 지금 차례 눈이 제자리에 톡 붙어요. 멈춤·벌점·경고 문구가 없어요.
  - 가이드를 끄면 점선과 “톡” 마커만 사라지고, 누르는 대로 같은 리듬으로 붙어요.
- 눈알 부착 애니메이션은 **0.15초**, 두 눈이 붙으면 **0.4초** 뒤 바로 다음 인형이 올라옵니다(`CONFIG.advanceDelay`).
  연타해도 `phase` 가드 덕분에 눈이 겹쳐 붙거나 두 번 기록되지 않아요.
- **5~9개마다** 하단에 가벼운 쉼표 배너가 7초간 떠요: “인형 10개 완성! 잠깐 쉬어갈까요?”
  - 그냥 두면 사라지고 계속 톡톡 붙일 수 있어요.
  - 배너를 **누른 사람만** 쉬어가는 카드가 열리고, 카드는 현황과 휴식 안내만 보여줘요.
    **광고는 재생하지 않아요**(전엔 “광고 없이 계속 / 광고 보고 계속”을 고르는 어색한 전면 광고 선택이 있었는데,
    보상이 없는 광고라 없앴습니다).
- **1박스 = 100개**를 채우면 가볍게 축하(`N박스 포장 완료!` + 색종이·팡파레)하고, 바가 잠시 초록빛으로 가득 찬 뒤
  **1.4초 뒤 다음 박스(0/100)로 이어집니다.** 목표에서 멈추지 않으니 게이지가 계속 움직여요.

### 특별 주문 인형 (랜덤 이벤트)

- 일반 인형을 5~9개 만들 때마다 **평균 7개에 한 번(약 12~14%)** 한 마리가 특별 주문으로 올라와요.
  첫 특별 주문은 3~5개째에 한 번 나와서 금방 볼 수 있어요. 같은 종류가 연달아 나오지는 않아요.
- 종류는 **3종**, 고른 동물(곰돌이 · 토끼)을 그대로 바탕으로 변주합니다.

  | 종류 | 생김새 |
  | --- | --- |
  | 황금 | 금빛 털 그라데이션 + 은은한 금빛 번짐 |
  | 리본 | 분홍빛 털 + 머리 위 나비 리본 |
  | 왕관 | 금빛 왕관 + 보석 3개 |

- 등장하면 인형 뒤로 은은한 빛이 천천히 번지고, 아래 한 줄에 `✨ 특별 주문 인형! 왼쪽 눈부터 톡`(랜덤 시작 쪽) 이 뜹니다.
- 완성하면 `✨ 특별 주문 완성! +60원` — 가상 기록이 **2배**(60원)로 쌓여요(집중 모드 중이면 4배 120원).
  이 문구를 읽을 수 있도록 특별 주문만 0.9초 머물러요(평소 0.4초).
  오늘 받은 특별 주문 수는 **더보기 → 설정 및 기록**에서 볼 수 있어요.
- 특별 주문도 다른 인형과 똑같이 랜덤 시작 눈 안내를 따릅니다. 판정·제한시간·등급·콤보가 없어요.

### 눈알과 가이드

- 눈알은 얼굴 대비 **큼직하게** 그립니다(흰자 rx 21.5 / 홍채 r 12.6, 하이라이트 반짝이 2개).
- 누르면 **꾹 눌렸다가 톡 붙는** 애니메이션과 본드가 살짝 번지는 느낌이 함께 나요.
- 가이드: 지금 눌러야 할 눈 자리에 **점선 원 + 가운데 “톡” 마커**가 표시됩니다.
  - 3개까지는 또렷하게, 이후에는 은은하게. 설정 및 기록에서 끌 수 있어요.
- 누르면 인형 얼굴 어디든 붙지만, 눈은 **지금 차례 눈 자리**에 정위치로 붙어요(살짝 자연스러운 흔들림만).
  판정이 없으니 짝눈·비뚤어진 눈이 생기지 않고, 누른 위치가 결과를 바꾸지도 않아요.

### 랜덤 눈 순서 (판정 없는 단순 안내)

- 인형이 올라올 때마다 `Math.random()`으로 `firstSide`(`left`/`right`)를 정하고, `guideIndex`가 지금 붙일 눈을 가리켜요.
  첫 눈을 붙이면 `phase`가 `first → second`로 넘어가며 `guideIndex`가 반대쪽으로 바뀝니다.
- 반대쪽 눈을 눌러도, 얼굴 다른 곳을 눌러도 **지금 차례 눈이 그대로 붙어요.** 흔들림·`miss` 효과음·경고 문구·콤보 초기화가 없습니다.
  (`combo`·`bestCombo`·콤보 칩·5연속/10연속 보너스는 코드에서 모두 제거 — 아래 §7 참고)
- 붙인 직후 `CONFIG.tapGuardMs`(220ms) 안의 추가 탭은 무시해요. 두 번 톡 하는 사이 손가락이 튀어 눈이 두 번 붙는 걸 막는 장치예요(판정 아님).
- 설정 및 기록은 **세 칸**(완성한 인형 · 오늘 완성 · 특별 주문)이에요.

## 3. 탭 바 · 시트

### 인형
곰돌이 / 토끼를 미니 얼굴 아이콘과 함께 고릅니다. 완성 직후(다음 인형이 올라오기 전)에는 바꿀 수 없다고 알려 줍니다.

### 테마
배경 테마 6종: **크림 · 살구 · 민트 · 버터 · 라벤더 · 스페셜**.
- 고른 테마는 배경·시트·카드·진행 바 색에 은은하게 반영됩니다(`state.theme`).
- **스페셜**은 광고를 끝까지 본 사람에게 한 번 열리고 계속 쓸 수 있어요(`state.specialRibbon`).

### 소리
효과음 On/Off. 끄면 아이콘에 사선이 그어지고 설정이 저장됩니다.

### 부스터
“광고 보고 30초 집중 모드”. **광고 사전 안내 → 데모 광고 → 30초 동안 가상 기록 2배**.
진행 중에는 상단에 `집중 N초` 칩과 부스터 탭 강조가 표시됩니다.

### 더보기
| 항목 | 동작 |
| --- | --- |
| 친구에게 공유 | 토스 브릿지 → `navigator.share` → 클립보드 복사 순서로 시도하고 토스트로 안내 |
| 알림 받기 | **버튼을 눌렀을 때만** 다크 바텀시트가 열립니다. “매일 인형 눈알 알림을 보내드릴까요? — 동의하고 알림받기 / 나중에” |
| 설정 및 기록 | 완성 수·오늘 수·오늘 특별 주문, 눈 위치 가이드 스위치, 기록 초기화 |
| 안내 및 출처 | 가상 기록 고지, 광고·알림 안내, 그림·사운드 출처(직접 제작), 저장 위치 |

- 알림은 진입 시 자동으로 묻지 않습니다(다크패턴 금지). 동의하면 `state.notify=true`, `state.notifyAt='20:00'`이 저장되고,
  `window.DollEyeNotification` 브릿지 또는 웹 알림 권한으로 넘깁니다. 다시 열면 **알림 끄기**가 나옵니다.

## 4. 가상 기록과 박스

| 항목 | 값 |
| --- | --- |
| 개당 가상 기록 | **30원** (부업 후기처럼 소박한 단가) |
| 특별 주문 인형 | **2배 (60원)** · 집중 모드 중이면 4배 |
| 집중 모드 | 광고 시청 후 **30초 동안 기록 2배** |
| 1박스 | **100개** (`CONFIG.boxSize`) — 채우면 다음 박스가 이어짐 |
| 박스 축하 | 100개째마다 1.4초 (`CONFIG.boxCelebrateMs`) |
| 오늘 기록 초기화 | 한국 날짜(Asia/Seoul)가 바뀌면 자동 |

> 표시되는 금액은 **가상의 숫자**이며 실제 현금·토스포인트·비즈월렛으로 지급되지 않습니다.
> 화면 하단 고지, 설정 및 기록, 안내 및 출처에서 같은 내용을 안내합니다.

수치 조정은 `app.js` 상단 `CONFIG` 한 곳에서 됩니다.

```js
var CONFIG = {
  appUrl: 'https://bubble-collab.github.io/doll-eye-job/',
  boxSize: 100,          // 1박스 = 100개 (채우면 다음 박스가 이어짐)
  boxCelebrateMs: 1400,  // 박스 완료 축하 표시 시간(ms)  recordPerDoll: 30,     // 개당 가상 기록(원)
  advanceDelay: 400,     // 다음 인형까지 대기(ms)
  eventGapMin: 5,        // 특별 주문 인형 간격(최소)
  eventGapMax: 9,        // 특별 주문 인형 간격(최대)
  eventBonusMultiplier: 2, // 특별 주문 가상 기록 배수
  focusSeconds: 30,      // 집중 모드 지속 시간
  restEvery: 10,         // 쉼표 배너 주기
  bannerHeight: 102,     // 하단 고정 배너 자리 높이(px)
  notifyTime: '20:00',   // 매일 알림 희망 시각
  promotionCode: '',     // 사업자 등록 후 발급받는 프로모션 코드
  adGroupIds: { rewardedFocus, rewardedSpecialRibbon, banner }
};
```

## 5. 광고 슬롯

| 슬롯 | 트리거 | 내용 |
| --- | --- | --- |
| `rewardedFocus` | 부스터 탭 | 30초간 가상 기록 2배 |
| `rewardedSpecialRibbon` | 테마 → 스페셜 배경 | 스페셜 배경 1회 해금(계속 사용) |
| `banner` | 화면 최하단 고정 배너(`#tossBannerSlot`) | 토스 `TossAds.attachBanner` · 높이 102px |

- **보상이 분명한 두 곳에만 광고를 붙입니다.** 쉬어가는 카드는 현황·휴식 안내만 보여주고 광고를 재생하지 않아요.
  (보상 없는 “광고 없이 계속 / 광고 보고 계속” 선택은 광고 구조 정리 때 없앴습니다.)
- 보상형 광고는 **사전 안내 모달**을 거칩니다. 버튼 안쪽에 “광고 시청 후 …” 문구가 상시 표시되고,
  안내 모달에는 “끝까지 보면 적용돼요. 중간에 닫으면 적용되지 않아요”가 붙습니다.
- 하단 배너는 앱을 쓰는 동안 조용히 계속 보이는 고정형이에요. 붙지 않을 때(`onNoFill`·실패)는
  **자리를 잡지 않아** 탭 바 아래에 빈 띠가 남지 않습니다.
- 사용자가 예상하지 못한 시점에 전면 광고를 띄우지 않습니다.

## 6. 호스트 브리지 연결

브리지가 없어도 데모·웹 동작으로 완전히 돌아갑니다. 토스 앱에서는 아래처럼 연결해 주세요.

### 친구에게 공유

```js
import { share } from '@apps-in-toss/web-framework';

window.DollEyeShare.register({
  share(payload) {
    // payload: { title, text, url }
    return share({ message: `${payload.text}\n${payload.url}` });
  }
});
```

- 연결이 없으면 `navigator.share`를 쓰고, 그것도 없거나 실패하면 **링크를 클립보드에 복사**한 뒤
  `링크를 복사했어요` 토스트를 띄웁니다(1.2초 안에 응답이 없으면 자동으로 복사 방식으로 넘어감).
- 사용자가 공유 시트를 닫은 경우(`AbortError`)에는 토스트를 띄우지 않습니다.

### 알림 받기

```js
import { requestNotificationAgreement } from '@apps-in-toss/web-framework';

window.DollEyeNotification.register({
  request({ time, title, body }) {
    // time: '20:00' · 사용자가 시트에서 "동의하고 알림받기"를 누른 뒤에만 호출됩니다.
    return requestNotificationAgreement({
      templateCode: 'doll-eye-daily',   // 콘솔에서 만든 스마트 발송 템플릿
      time
    }).then(() => ({ registered: true }));
  },
  cancel() {
    return Promise.resolve({ canceled: true });
  }
});
```

- 브릿지가 없으면 브라우저 알림 권한을 **동의 후에만** 요청하고, 동의 상태는 로컬에 저장합니다.
- 실제 매일 발송은 토스 스마트 발송(템플릿) 쪽에서 이뤄집니다. 웹 단독 배포에서는 권한·동의 상태만 남습니다.

### 프로모션 보상 (사업자 등록 후)

```js
import { grantPromotionReward } from '@apps-in-toss/web-framework';

window.DollEyePromotion.register({
  grant(promotionCode) {
    return grantPromotionReward({
      params: { promotionCode, amount: 100 }
    }).then((res) => ({ granted: !!(res && res.success) }));
  }
});
```

- 앱은 **첫 박스(100개)를 처음 채웠을 때 한 번만** `grant()`를 호출합니다.
- `CONFIG.promotionCode`가 비어 있거나 호스트가 연결하지 않았으면 조용히 아무 일도 하지 않습니다.

### 뒤로가기 · 종료

```js
import { Screen, graniteEvent } from '@apps-in-toss/web-framework';

window.DollEyeHost = { exit: () => Screen.close() };

const unsubscribe = graniteEvent.addEventListener('backEvent', {
  onEvent: () => window.DollEyeApp.requestExit(),

window.addEventListener('pagehide', () => unsubscribe());
```

### 광고 SDK (통합 광고 2.0)

```js
import { loadFullScreenAd, showFullScreenAd } from '@apps-in-toss/web-framework';

window.DollEyeAdBridge.register({
  show(kind, adGroupId) {
    return new Promise((resolve, reject) => {
      loadFullScreenAd({
        options: { adGroupId },
        onEvent: (e) => {
          if (e.type !== 'loaded') return;
          showFullScreenAd({
            options: { adGroupId },
            onEvent: (ev) => {
              // ✅ 보상은 userEarnedReward에서만 지급 (dismissed는 보상 아님)
              if (ev.type === 'userEarnedReward') resolve({ rewarded: true });
              if (ev.type === 'dismissed' || ev.type === 'failedToShow') resolve({ rewarded: false });
            },
            onError: reject
          });
        },
        onError: reject
      });
    });
  }
});
```

- `load → show → 다시 load` 순서를 지켜 주세요.
- ⚠️ **다른 앱에서 쓰던 광고 그룹 ID를 재사용하면 정적 분석에서 반려됩니다.** 앱마다 새로 발급받아
  `CONFIG.adGroupIds`에 넣어 주세요. 지금 값은 앱인토스 문서의 **테스트 전용 ID**입니다.

### 하단 고정 배너 (TossAds.attachBanner)

```tsx
import { TossAds } from '@apps-in-toss/web-framework';

TossAds.initialize({
  callbacks: {
    onInitialized() {
      window.DollEyeBanner.register({
        attach(adGroupId, container, events) {
          // 고정형: 컨테이너는 width 100% · height 102px (#tossBannerSlot)
          return TossAds.attachBanner(adGroupId, container, {
            theme: 'auto',
            tone: 'blackAndWhite',
            variant: 'expanded',
            callbacks: {
              onAdRendered: events.onRendered,
              onNoFill: events.onNoFill,
              onAdFailedToRender: events.onFailed
            }
          });
        }
      });
    },
    onInitializationFailed(error) {
      console.error(error);
    }
  }
});
```

- 토스 앱 **5.241.0 이상**에서만 배너가 지원돼요. 그 아래에서는 배너 자리 없이 앱이 그대로 동작합니다.
- 앱 쪽 컨테이너는 `index.html` 의 `#tossBannerSlot` (width 100% · height `CONFIG.bannerHeight`=102px) 이고,
  앱이 여기에 **직접 DOM을 넣지 않아요**(SDK가 채우는 자리).
- 브릿지가 붙으면 `body.has-banner` 가 켜져 앱 여백(`--banner-h`)이 102px만큼 줄고, 탭 바는 배너 위로 올라갑니다.
  토스트·쉼표 배너·바텀시트도 같은 높이만큼 함께 올라가 가리지 않아요.
  `onNoFill`·`onAdFailedToRender` 가 오면 자리를 다시 접어 빈 띠를 남기지 않습니다.
- 웹 미리보기: 브릿지가 없으면 배너 자리를 잡지 않아요(탭 바가 화면 맨 아래). 배너가 들어온 모습을 보려면
  `https://bubble-collab.github.io/doll-eye-job/?banner=1` 로 열어 보세요 — 102px 자리에 안내문이 표시되고
  탭 바·토스트 위치가 함께 올라간 레이아웃을 확인할 수 있습니다.
- 특별 주문 인형 모양 미리보기: `?event=gold` · `?event=ribbon` · `?event=crown` (첫 인형만 지정한 종류로).

## 7. 비게임(엔터테인먼트) 출시 기준 정리

이 앱은 **비게임(엔터테인먼트)** 으로 출시합니다. 그래서 승패·점수·콤보·등급·제한시간·순위를 코드에 두지 않았어요.

| 승패·판정(PERFECT/GOOD/불량) | **없음** — 누르면 늘 정위치에 붙어요 |

## 8. 구현 포인트

### 인형 · 눈

- 곰돌이·토끼를 인라인 SVG로 직접 그렸습니다(그라데이션 털, 스티치, 볼터치).
- 인형마다 `viewBox`를 따로 두어(`viewBox` 크롭) 화면 폭을 거의 채우면서 위아래 여백을 줄였습니다.
- 눈은 `<g class="eye">`로 생성: 흰자·홍채·하이라이트 2개, `translate / rotate / scale`로 배치.
- 등장 시 `eyePress` 애니메이션(0.15초)으로 꾹 눌리며 붙는 느낌, `ripple`·`glue`(0.32~0.34초)로 본드가 번지는 연출.
- 인형 그림은 `bearBody(kind)` / `rabbitBody(kind)` 로 색 팔레트와 장식을 받아요. `kind` 가 없으면 기본 인형,
  `gold`·`ribbon` 이면 털 그라데이션과 볼·주둥이 색이 바뀌고, `crown`·`ribbon` 은 머리 위 장식(`eventDecor`)이 붙습니다.
  인형 뒤 은은한 빛은 `<ellipse class="event-glow">` 하나로 처리해 프레임 부담을 늘리지 않았어요.
- 빠른 연타 대비: 두 번째 눈을 붙이면 `phase='done'` 이 되고, 다음 인형이 올라오기 전(0.4초)의 입력은 무시됩니다.
  붙인 직후 220ms(`CONFIG.tapGuardMs`)의 추가 탭도 무시해, 더블 탭이 실수로 기록되지 않아요.
- 랜덤 눈 순서: `firstSide`(left/right) → `guideIndex`(0/1) 로 바꿔 쓰고, 첫 눈 뒤 `phase`를 `first → second`로 넘기면서 `guideIndex`만 뒤집어요. 가이드와 한 줄 힌트가 모두 이 한 값을 보고 움직입니다(판정 없음).
- 눈은 `placeEye(guideIndex)` 한 곳에서 정위치(`DOLLS[].eyes`)로 붙여요. 누른 좌표는 "얼굴을 눌렀는지"(`hitRadius`) 확인에만 쓰고, 붙는 위치·판정에는 쓰지 않습니다.

### 사운드 (iOS 사파리 · 토스 웹뷰 대응)

- Web Audio API로 `톡 / 뽁 / 딩동 / 팡파레 / UI`를 오실레이터+노이즈로 합성합니다. 음원 파일이 없습니다.
- 첫 `pointerdown`마다 `AudioContext`를 **resume + 무음 버퍼 재생**으로 잠금 해제합니다.
- `visibilitychange`로 앱 복귀 시 `resume()`, 소리 탭으로 음소거(설정은 저장됨).

### 저장

- `localStorage` 키 `doll-eye-job.v2`에 누적/오늘 완성 수, 가상 기록, 특별 주문 수(`eventToday`, `eventTotal`),
  목표 달성 대신 박스 채운 횟수(`lastBox`), 테마, 스페셜 배경, 가이드, 소리, 알림 동의(`notify`, `notifyAt`)를 저장합니다.
- 날짜가 바뀌면(Asia/Seoul 기준) 오늘 기록·오늘 특별 주문·`lastBox`만 초기화되고 누적 기록은 유지됩니다.
- 특별 주문이 나오는 간격(`eventCountdown`)은 화면 안에서만 세다가 새로 열면 3~5개째부터 다시 잡아요.
- 저장이 막힌 환경(사생활 보호 모드 등)에서도 동작은 정상입니다.

### 뒤로가기 · 종료 확인

- 첫 화면에서 뒤로가기(앱 내 ← 버튼 또는 기기 뒤로가기)를 누르면 **종료 확인 모달**이 뜹니다.
- `history.pushState` 가드 + `popstate`로 브라우저/웹뷰 뒤로가기를 가로채고, 시트·모달이 열려 있으면 뒤로가기는 그것만 닫습니다.

## 11. 알려진 한계

- 광고는 **데모**입니다. 실제 수익·노출은 SDK 연결 후에 발생합니다.
- 프로모션 보상은 자리만 있고, 사업자 등록·코드 발급·호스트 연결 전에는 동작하지 않습니다.
- 알림은 동의 상태만 저장합니다. 실제 매일 발송은 토스 스마트 발송 템플릿 연결이 필요합니다.
- 공유는 `navigator.share`가 없는 데스크톱에서 클립보드 복사로 대체됩니다(권한이 막히면 실패 토스트).
- 기록은 기기 브라우저에만 저장됩니다(서버 동기화 없음).
- 인형 그림은 SVG 도형 기반이라 실제 봉제 질감과는 다릅니다(프로토타입 수준).
